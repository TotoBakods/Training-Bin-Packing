## 3. Preprocessed Output - Normalized (Model Input/Output)
These samples show the data scaled for the Neural Network. Inputs are scaled by fixed factors (e.g., /10, /100) or relative to warehouse dimensions. Targets are mapped to [0, 1].

### Feature Normalization logic (19 Features):
1. **Geometric**: `l/10, w/10, h/10`, `vol/10, area/10`
2. **Weight/Physics**: `weight/100, fragile, stackable, can_rotate`
3. **Warehouse Context**: `wh_l/100, wh_w/100, wh_h/100, wh_vol/1000, wh_area/100`
4. **Relative Ratios**: `item_vol/wh_vol`, `item_area/wh_area`, `l/wh_l`, `w/wh_w`
5. **Sequence**: `index/total_items`
